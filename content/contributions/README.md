# Contributions drop zone

Draft crossword puzzles land here, one authoring template per
puzzle, named `<your-tag>-<slug>.md`, with the validator-generated
`.json` of the same name beside it.

Start with `AGENTS.md` at the repository root and
`docs/puzzle-authoring/BRIEF.md` — they govern. Drafts here are
**not** part of the library: a puzzle moves into `content/` only
when a reviewer banks it after the D54 gates (editorial review,
correctness review, clean cold playtest, and the author of record's
written CC0-1.0 attestation) are complete.
